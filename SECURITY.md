# Security policy

## Reporting a vulnerability

Please report security problems privately. Open the **Security** tab of this repository and choose **Report a vulnerability**. This sends a private report to the people who maintain this site.

If you can't use that, email both rs@usenaw.com and gm@usenaw.com.

Never open a public issue or pull request about a security problem. Everything in them is public.

## What to include

- the address of the page;
- what you found, and what an attacker could do with it;
- the steps to reproduce it;
- how we can reach you with questions.

Please don't access data that isn't yours, and don't run tests that slow the site down for other visitors.

## Supported versions

Only the version of the site that is live now is supported.
